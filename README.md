# 🎯 Lead Scraper Suite — Setup Guide

## Files List
```
main_launcher.py   ← Main file (3 tabs in 1 window)
build.bat          ← Windows pe EXE banane ke liye
build.sh           ← Mac/Linux pe build ke liye
README.md          ← Ye file
```

---

## ▶ Directly Run Karna (Python se)

```bash
pip install selenium pandas openpyxl webdriver-manager requests
python main_launcher.py
```

---

## 📦 EXE Banana (Windows)

1. `build.bat` pe double-click karo
2. Automatically install + build hoga
3. `dist\LeadScraperSuite.exe` ready mil jayega
4. Ye `.exe` kisi bhi Windows PC pe chalega — Python ki zaroorat nahi

---

## 🚀 GitHub se Download Link Dena

1. GitHub pe naya repo banao
2. Ye saari files upload karo
3. `build.bat` run karo apne PC pe
4. `dist\LeadScraperSuite.exe` ko GitHub Releases pe upload karo
5. Download link share karo — koi bhi `.exe` click kare aur use kare

## ⚠ Important Notes

- Chrome browser install hona chahiye PC pe
- Internet connection zaroor honi chahiye
- Google Maps scraping slow hoti hai — patience rakho
- `.exe` file ~80-120 MB ki hogi (normal hai)
